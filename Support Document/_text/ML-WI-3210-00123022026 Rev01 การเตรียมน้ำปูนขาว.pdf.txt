2. เครื่องมือ/อุปกรณ์
2.1. ( แบบเก่า )
1 ปูนขาวก้อน 6 ถังพักน้าปูนขาว
2 สะพานลาเลียงปูนขาว 7 ไฮโดรมิเตอร์
3 ถังละลายปูนขาว 8 พลั่วตักปูน
4 ตะแกรงกรองน้าปูนขาว ( แบบมอเตอร์เขย่า )
5 ถังเตรียมน้าปูนขาว
2.2 ( แบบให่ม )
1 ปูนขาวผง 6 ถังผสมปูนขาว ( Mixing tank No.1&2 )
2 การใช้ลมเตีมปูนขาวผงจากรกขนปูนเข้าถังเก็บ 7 ไฮโดรมิเตอร์
3 ถังเก็บปูนขาวแบบผง ( Silo tank )
4 วาล์วเปีด-ปิด ( Knifte Gate Valve )
5 สกรูลาเลียง ( Screw Conveyor )
3. คานิยาม
4. เอกสารอ้างอิง

5. ผู้รับผิดชอบ
5.1 หัวหน้ากะ ทาหน้าที่ ดูแลงานในแผนก
5.2 ช่างควบคุมฮีตเตอร์ ทาหน้าที่ ดูแลงานเตรียมน้าปูนขาว
5.3 พนักงานรายวัน ทาหน้าที่ เตรียมน้าปูนขาว
6. วิธีการปฏิบัติงาน ( ปูนขาวก้อน )
6.1 การเตรียมความพร้อมก่อนปฏิบัติงาน
โดยเตรียมให้พร้อมก่อนใช้งาน อย่างน้อย 2-4 ชั่วโมง
6.2 การเดินเครื่องจักร
6.2.1 เดินใบกวนถังละลายปูนขาว และเดินสะพานลาเลียงปูนขาวลงถัง ละลายเปิดน้าร้อนหรีอน้าเย็นลงถังละลายปูนขาว
ที่ระดับ 30-50% ของถัง Mixing
6.2.2 ตักปูนขาวก้อนใส่สะพานลาเลียงไปลงถังละลาย โดยผู้ปฏิบัติงานต้องสวมใส่อุปกรณ์ป้องกันและแต่งกายรัดกุมมิดชิด
6.2.3 เก็บตัวอย่างน้าปูนขาวจากถังละลายโดยใช้กระบอกตรงขนาด100 cc ตักจนเต็มแล้วใช้ ไฮโดรมิเตอร์
วัดความเข้มข้นให้ได้ ตามแผนคุณภาพ (ML-SP-3000-001) ตรวจสอบความเข้มข้นของน้าปูนขาว
บันทึกลงในบันทึกการเตรียมน้าปูนขาว ML-FM-3212-005
6.2.4 เปิดน้าปูนขาวไหลผ่านตะแกรงแล้วผ่านลงถังเตรียมน้าปูนขาว พร้อมเดินใบกวนถังเตรียม ที่มีระดับน้าปูนขาว
ประมาณ 50% ให้เดินปั้มไปลงถังพัก พร้อมเดินใบกวนที่ถังพักน้าปูนขาว
6.2.5 เปิดปั้มน้าปูนขาวจากถังพักส่งไประบบเตรียมไลม์แซ็กคาเรทโดยเดินปั้มให้น้าปูนขาวไหลเวียนกับตลอดเวลา
เพื่อป้องกันไม่ให้น้าปูนขาวตกตะกอน อุดตันท่อ
6.2.6 ทาความสะอาดตะแกรงกรองน้าปูนขาวอย่างน้อย 8 ชั่วโมง/ครั้ง โดยใช้ ไม้คฑาโกยสิ่งสกปรกออก แล้วตักลงรถเข็น
นาไปทิ้งที่จุดฝังกลบขยะที่โรงงานกาหนด
บริษัท น้าตาลมิตรลาว จากัด
วิธีปฏิบัติงาน (Work Instruction)
เพื่ออธิบายวิธีการปฏิบัติงาน การเตรียมน้าปูนขาว
รายละเอียด
6.3 การแก้ไขปัญหาที่เกิดขึ้น
6.3.1 ถ้าความเข้มข้น ต่ากว่า ค่าควบคุม ให้เพิ่มการเติมปูนขาวก้อน
6.3.1 ถ้าความเข้มข้นมากกว่า ให้เปิดวาล์วน้าร้อนหรีอน้าเย็นเข้าผสม
6.4. บันทึกคุณภาพที่เกี่ยวข้อง
บันทึกการปฏิบัติงานของระบบฮีตเตอร์ ML-FM-3212-005
6.5. ข้อควรระมัดระวังขณะปฏิบัติงาน
- กวาดเอากากปูนขาวออกอยู่เสมอเพื่อป้องกันการอุดตันของตะแกรง
- แต่งกายให้รัดกุมป้องกันอันตราย
- ใส่อุปกรณ์ Safety
7. วิธีการปฏิบัติงาน ( ปูนขาวผง )
7.1 การเตรียมความพร้อมก่อนปฏิบัติงาน
7.1.1 การเตรียมก่อน Start
1. ตรวจสอบ Lime ใน Silo ให้อยู่ในระดับทื่เพียงพอ
2. ตรวจสอบวล์ว Knife Gate เปีด-ปิด ปกติ
3. ตรวจสอบ Rotary Feeder และ Screw Conveyor พร้อมใช้งาน
4.ตรวจสอบระบบน้า และ ตั้งค่า Water Flow Rate ตามกาหนด
5.ตรวจสอบ Level Mixing Tank No.1 และ No.2
6.ตั้งค่า Parameter ดังนี
Lime Feed Rate (kg/hr)
- Water Flow Rate (m3/hr)
- %Baume
- Time to Mixing
โดยเตรียมให้พร้อมก่อนใช้งาน อย่างน้อย 1-2 ชั่วโมง
7.2 การเดินเครื่องจักร ( ระบบไชโล จะมีอยู่ 2 ระบบ Auto & Manual และ มี 2 ถัง Mixing ทางานสลับกัน (Alternating Tank) )
7.2.1 การเดินเครี่องระบบ Auto (ถัง Mixing 2 ถัง)
1) ขั้นตอนการเดินเครี่อง Auto
ระบบประกอบด้วย
• Mixing Tank No.1
• Mixing Tank No.2
ระบบจะเลือกถังที่ระดับต่ากว่า Level SP to Start เพื่อทาการผสม
1.เลีอกโหมด PROCESS CONTINUOUS
2.กดปุ่ม START/RUN
3.ลาดับการทางานอัตโนมัติของระบบ
- เงี่อนไขเบี้องต้น : เมื่อถังใดถังหนึ่งมีระดับต่ากว่า Level SP to Start ระบบจะเลือกถังนั้นเพื่อทาการผสม
- ขั้นตอนการทางาน 1 : ระบบจะทาการเปีดวาล์วน้าเข้าถัง Mixing No.1 ให้ได้ระดับน้าอยู่ทื่ 10% หลังจากนั้นระบบก็จะเดินใบกวน
-
ขั้นตอนการทางาน 2 : ระบบจะทาการ เดิน Screw Conveyor , Rotary Feeder , Kinfe Gate Valve
- ขั้นตอนการทางาน 3 : ระบบจะควบคุมอัตราส่วน Lime Feed , ควบคุม Water Flow ตาม Ratio ทื่ตั้งไว้เพี่อให้ได้ตามค่าควบคุม %Baume
- เงี่อนไขการหยุดจ่าย : เมื่อระดับของถังนั้นถึงค่า Level SP to Stop 100 % ระบบจะ ปิด Knife Gate Valve,หยุด Rotary Feeder,หน่วงเวลาให้
Screw Conveyor เคลียร์ปูน , หยุด Screw Conveyor , ปิดวาล์วน้าและ Mixer หรีอใบกวน ทางานต่อจนครบเวลา Mixing
4.ระบบการผสมสลับถังอัตโนมัติ : เมื่อถังที่ 1 ผสมเต็มแล้ว (100% Level SP to Stop) และ ถัง 2 มีระดับต่ากว่า ( 10% Level SP to Start ) ระบบจะทาการสลับไปผสมยังอีก
ถังโดยอัตโนมัติ และ ถ ้าหากระบบทางานผิดปกติให ้กด Stop ระบบจะหยุดให ้ทั้งหมด
รายละเอียด
7.2.2 การเดินเครี่องจักร Manual
1) ขั้นตอนการเดินเครี่องจัก Manual
กรฌีทื่ใช ้โหมด Manual
• ระบบ Auto ขัดข ้อง
2.ลาดับการเดินเครี่อง Manual ( Opertor ต ้องควบคุมเองทุกขั้นตอน )
ขั้นตอนการทางาน 1 : เลือกถังทื่ต ้องการผสม เปีดวาล์วน้าเข ้าเฉพาะถังนั้น และ ปิดวาล์วน้าเข ้าอีกถังให ้สนิท
ขั้นตอนการทางาน 2 : หลังจากน้าเข ้าถังได ้ระดับ 10% ให ้เดิน ใบกวน ก่อนจ่ายปูน
ขั้นตอนการทางาน 3 : เรี่มจ่ายปูน ( เปีดจากล่างขี้นบน ) เดิน Screw Conveyor,เดิน Rotary Feeder,เปีด Knife Gate Valve
ขั้นตอนการทางาน 4 : ควบคุมระดับและความเข ้มข ้น เช่น เฝ้าดูระดับถังตลอดเวลา และ ตรวจเช็ค%Baume ตอนผสมแล ้วเส็จ
ขั้นตอนการทางาน 5: การหยุดเครี่อง แบบ Manual เมื่อได ้ตามระดับทื่ต ้องการแล ้ว หรีอใกล ้เต็มถัง ให ้หยุดจากบนลงล่าง
- ปิด Knife Gate Valve
- หยุด Rotary Feeder
- รอให ้Screw Conveyor เคลียร์ปูน
- หยุด Screw Conveyor
- ปิดวาล์วน้า
- ให ้Mixer ทางานต่อไปอีกระยะ แล ้วจริงหยุด
7.2.3 การแก้ไขปัญหาที่เกิดขึ้น ของระบบ Auto & Manual
1) ปัญหา : ปูนไม่ลง / ไม่จ่ายปูน
สาเหตุ : Knife Gate ไม่เปีด
Rotary Feeder / Screw Conveyor ไม่ทางาน
ปูนจับตัวเป็นก ้อน ( อุดตัน )
การแก ้ไข : ตรวจเช็คสถานะมอเตอร์ และ Overload
หยุดเครี่องก่อนเคลียร์การอุดตัน
2) ปัญหา : %Baume ไม่ได ้ตามค่าควบคุม
สาเหตุ/การแก ้ไข : อัตราน้ามาก/น้อยเกินไป
Baume ต่า
เพี่ม % ปูนขาวเพี่ม ลดปริมาณน้าลง
สาเหตุ/การแก ้ไข : Baume สูง
ลด%ปูนขาวลง เพี่มน้าขี้น
7.3. บันทึกคุณภาพที่เกี่ยวข้อง
บันทึกการปฏิบัติงานของระบบฮีตเตอร์ ML-FM-3212-005
7.4 ข้อควรระมัดระวังขณะปฏิบัติงาน ของ 2 ระบบ
7.4.1 ข้อควรระวังระบบ Auto
- ต ้องมีน้าเข ้า ก่อนจ่ายปูนทุกครั้ง
- Mixer ต ้องทางานก่อนจ่ายปูน
- ห ้ามเปีดรับ 2 ถังพร ้อมกัน
- ตั้งค่า Level Start-Stop ( Start 10% , Stop 100% )
- เกีด Alarm ให ้หยุดและตรวจสอบก่อน Restart
7.4.2 ข้อควรระวังระบบ Manual
- เปีดจากล่างขี้นบน ( Screw - Rotary - Gate )
- หยุดจากบนลงล่าง ( Gate - Rotary - Screw )
- ห ้ามจ่ายปูนโดยไม่มีน้า
- ต ้องเฝ้าระดับถังตลอดเวลา
- ตรวจเช็ค % Baume
