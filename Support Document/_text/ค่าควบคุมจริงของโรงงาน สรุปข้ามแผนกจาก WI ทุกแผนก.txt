**ML-WI-3110-010 Rev.02 — การแก้ค่าควบคุมไม่เข้าเป้า 6 กรณี (อ่านครบทั้งเล่มแล้ว):**
1. **PI ต่ำ**: เช็กคมฆ้อนตีอ้อย + Grid Bar เมื่อหยุดหีบ → ทดลองเร่งตะแกรงเครื่องย่อย 3–5 mm (ถ้ามีเสียงค้อนตีที่ Grid Bar ให้ถอยกลับ) → เช็กมีดฟันอ้อยทุกชุด → ติดตามใน ML-FM-3110-013 → ยังไม่ผ่านเสนอผู้บังคับบัญชา + ปรับปรุงตาม ML-WI-3110-003
2. **Pol %Bagasse สูง**: เพิ่มน้ำร้อนพรมกากชุดสุดท้าย (โดยไม่ให้กระทบ Brix น้ำอ้อยรวม) → เช็กความดันไฮดรอลิกกดหัวลูกหีบ **ชุด 1–5 ที่ 2,000–2,800 psig**
3. **Moisture กากสูง**: ปรับน้ำพรมให้เหมาะกับปริมาณกากก่อนเข้าชุดสุดท้าย ใช้ข้อมูล Pol%Bagasse ช่วงก่อนหน้าประกอบ
4. **Purity Drop สูง**: ล้างจุดอับที่เกิดแบคทีเรีย (ซอกแท่นลูกหีบ ขอบราง ปากถัง ตะแกรงโรตารี่) ด้วย**น้ำร้อน/ไอน้ำเท่านั้น** เพิ่มความถี่ · ใช้น้ำร้อนให้น้อยที่สุด เขี่ยกากบ่อยๆ ไม่ให้สะสม
5. **Brix น้ำอ้อยรวมต่ำ**: อย่าปรับทันที — เทียบผลย้อนหลังรายชั่วโมงก่อน (กระทบ Pol bagasse/extraction) → ลดน้ำร้อนฉีดล้างตะแกรง/ลูกหีบ → เช็กน้ำนอกระบบรั่วผสมน้ำอ้อย → ถ้า Pol%Bagasse ยังดี ค่อยลดน้ำพรมกากอีก
6. **1st Mill Extraction ต่ำ**: มีดฟันอ้อย/ฆ้อน Shredder **สึกเกิน 20% ของขนาดเดิม → เปลี่ยน/กลับหน้า** → เพิ่มไฮดรอลิกชุด 1 (2,000–2,800 psi) → ปรึกษาปรับ Mill Setting (ML-FM-3110-019)
- ข้อควรระวังสำคัญ: **น้ำร้อนพรมกากชุดสุดท้ายต้อง >75°C** (อ้าง ML-SP-3110-003 หน้า 4/22) ต่ำกว่าให้ประสานหม้อเคี่ยวปรับ · ก่อนปรับแต่งใดๆ ดูค่าเฉลี่ยประจำวัน/Period จาก Daily Report ก่อน · Hydraulic Top cap บันทึกใน ML-FM-3110-007

**ML-SP-3110-003 Rev.02 (Support Document การหีบอ้อย 22 หน้า) — ทฤษฎี + ตารางตั้งค่า:**

**Lime saccharate + ฮีตเตอร์ (3210-003)**
- อัตราส่วนน้ำปูนขาว : น้ำเชื่อมดิบ = 1:1 หรือ 1:2 (ควบคุม pH ตามแผนคุณภาพ)

- ค่าควบคุม: ออกจากฮีตเตอร์ No.4 **≥70°C**, ออกจาก No.9 **≥103°C** · ต่ำกว่า → ตันแล้ว (ดูจาก ΔP >1 Bar หรือใช้งานเกิน 7 วัน) หยุดล้างสลับลูก
- pH น้ำอ้อยผสม: >7.6 ลดวาล์วปูน, <7.2 เพิ่ม lime saccharate

**ต้มน้ำอ้อย/Evaporator 5 ชุด (3210-006 Rev.06)**
- แว็คกั้มหม้อชุด 5: **500–600 mmHg** (ต่ำกว่า 600 ให้ไล่เช็กระบบ/เพิ่มน้ำ Jet condenser, control valve น้ำ ~50–60%)
- ไอเสียเข้า E1: ความดัน **0.6–1.5 kg/cm²**, อุณหภูมิ **120–125°C** (สูงเกิน → เช็ก De-Superheat)

**ตรรกะแก้ค่าไม่เข้าเป้า (ใช้ตอบ "ค่า X หลุด ทำไง"):**
- Vacuum ตก <620 → เปิดน้ำ Condenser เพิ่ม + หรี่ไอเคี่ยว
- เกิดฝ้าเม็ดเล็ก (false grain) → เปิดน้ำร้อนละลายแล้ว Set Brix ใหม่ · ล้างคัดเม็ดให้เหลือเม็ด 4–5 รุ่น
- Brix ต่ำ → ยืดเวลาเคี่ยว/เพิ่มไอ/เช็กแรงดันน้ำ + ดูกระแสมอเตอร์ก่อนลงน้ำตาลทุกครั้ง (A-Mass: Gillett meter >4.0 cm = ผลึกพอ)
- Purity ต่ำ → เพิ่ม Magma/Seed ฐาน, Purity สูง → ลดฐาน หรือ Back Mol 5–10% (A: Back Mol-A · B: Back B-Mol · C: Back C-Mol 5%) — ช่างต้องคำนวณ Coefficient of Saturation เป็น
- Purity Drop ต่ำ → เลี้ยงน้ำ 5–10 นาทีก่อนลงน้ำตาล + ปรับสัดส่วนเชื้อ (Purity Drop สัมพันธ์กับสีน้ำตาล)
- MA/CV หลุด → ปรับฐานเชื้อไล่ตั้งแต่ C-Seed ขึ้นมา + ล้างคัดเม็ดตอนเคี่ยว Seed
- ไฟดับ/Vacuum ตกหนัก: ปิดวาล์วป้อน → ปิดไอเคี่ยว → ปิดน้ำ Jet Condenser → ปิดวาล์วดักหน้าหม้อ → เปิดโบลว์ → แจ้งหัวหน้ากะ/วิศวกร (ขอไฟมาเดินใบกวนหัวหม้อ)
- **CCP น้ำตาล DCR (CCPB1): อุณหภูมิน้ำตาลในหม้อ >63°C ต่อเนื่อง 45 นาที** บันทึกใน ML-FM-3220-003 ช่องเฉพาะ DCR
- ผลวิเคราะห์หลุดค่าควบคุม >3 ครั้งติดกัน → แผนกวิเคราะห์ออก NCR (ML-FM-1610-005) ผ่าน e-Smart ISO
